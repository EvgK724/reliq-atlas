# RELIQ — Семь вещей. Не все ответы.

Русскоязычный атлас семи реальных исторических предметов с неоновыми схемами, разбором научных объяснений и тренировкой памяти. Тёмный графитовый фон, бирюзовые линии, янтарные акценты и три размера крупного текста рассчитаны на чтение с телефона и планшета.

[Открыть RELIQ](https://evgk724.github.io/reliq-atlas/) · [Исходники](https://github.com/EvgK724/reliq-atlas)

## Коллекция

| Предмет | Главный вопрос |
| --- | --- |
| Антикитерский механизм | Как выглядели утраченные части и где его изготовили? |
| Кубок Ликурга | Как мастера получали и контролировали необычный цвет стекла? |
| Меч с надписью Ulfberht | Откуда происходили сталь и клинки с этой надписью? |
| Фестский диск | Как прочитать систему знаков и определить содержание? |
| Рукопись Войнича | Что записано, кем и по каким правилам? |
| Додекаэдр Нортон-Дисней | Для чего служил тщательно отлитый многогранник? |
| Диск Сабу | Каково назначение каменного сосуда необычной формы? |

Это авторская подборка, а не научный рейтинг. Неизвестная мастерская, спорная реконструкция процесса, утраченная функция и непрочитанный текст — разные виды неопределённости. Объяснённые свойства каждого предмета представлены рядом с открытыми вопросами.

## Как пользоваться

- **Атлас:** выбрать предмет, изучить крупную схему, переключиться между видом «Предмет» и «Разбор», увеличить изображение. Рядом находятся размеры, материал, датировка, происхождение, место хранения и пояснения.
- **Сравнить:** сопоставить то, что подтверждено наблюдениями, и то, что остаётся предметом исследования.
- **Повторить:** выбрать тему и тип карточек, самостоятельно вспомнить ответ, открыть пояснение и отметить «Ещё раз» или «Вспомнил». Переход к предмету из карточки сохраняет текущую тренировку.

**28 карточек** охватывают факты, связи и разбор примеров. Баллов, экзаменационного порога и обязательного числа заданий нет. История появляется только после явной отметки пользователя. «Ещё раз» назначает возврат через 10 минут; последовательные отметки «Вспомнил» дают интервалы 1, 3, 7, 14 и 30 дней.

Состояние повторений и размер текста хранятся локально в браузере. Между устройствами они автоматически не синхронизируются. Очистка данных сайта удаляет сохранённую историю. Если браузер запрещает сохранение, приложение сообщает об этом и откладывает автоматическое обновление.

## Графика

Семь оригинальных SVG содержат по два вида — **14 графических представлений**: предмет и объяснение устройства, материала или способа исследования. SVG встроены в готовый HTML и сохраняют чёткость при увеличении.

Изображения имеют учебный характер. Они не подменяют обмеры, музейные фотографии, микрофотографии или факсимиле. Например, условные знаки на диске и странице Войнича не являются точной транскрипцией; геометрия додекаэдра построена как двенадцатигранник, но его отверстия не следует измерять по экрану. Конкретные ограничения указаны в приложении.

## Источники и границы выводов

Данные находятся в `content.json`, библиография — в `sources.json`. У источников описано, какие утверждения они поддерживают. Приоритет отдан музейным каталогам, первичным отчётам, университетским публикациям и научным статьям. Внешние страницы могут менять адреса или ограничивать автоматический доступ; для перехода к ним требуется интернет.

При обновлении материала необходимо сохранять следующие различия:

- дата материала и дата нанесения текста;
- наблюдаемый след и вывод о его причине;
- работающая современная копия и доказанное древнее применение;
- известная технология и неизвестный конкретный рецепт;
- свойства одного исследованного экземпляра и свойства всей группы предметов.

У рукописи Войнича интервал 1404–1438 относится к пергаменту. Для додекаэдра Нортон-Дисней в официальных источниках расходятся значения массы 245 и 254 г, поэтому используется округлённая величина с пояснением. Гипотезы изложены как гипотезы и сопровождаются вопросом о том, какие данные могли бы их проверить.

## Сборка

Для основной сборки нужен Python 3; сторонние пакеты не требуются. Из корня репозитория:

```sh
python3 scripts/build.py
```

Результаты:

- `docs/index.html` — версия для GitHub Pages;
- `docs/RELIQ.html` — автономный файл с текстами, SVG, стилями и тренировкой;
- `docs/version.json` — идентификатор текущей сборки;
- `docs/assets/` — иконки, QR-код и исходные SVG.

Чтобы дополнительно скопировать автономное приложение в выбранную папку:

```sh
python3 scripts/build.py --export exports
```

Экспорт появится в `exports/RELIQ.html`. Готовый HTML генерируется из `src/`, `content.json`, `sources.json` и графики. Содержательные правки следует вносить в исходники, затем повторять сборку.

Иконки и QR уже входят в репозиторий. Для их регенерации предусмотрены `scripts/icons.cjs` и `scripts/qr.py`: нужны Node.js с Playwright/Chromium и Python с ReportLab/Pillow соответственно.

## Локальный просмотр и проверка

```sh
python3 -m http.server 8771 --directory docs
```

Откройте `http://localhost:8771/`. Проверка двигателя интервалов:

```sh
node tests/learning.cjs
```

Функциональные проверки в Chromium и WebKit (нужны Playwright и установленные браузеры):

```sh
node tests/browser.cjs
```

Переменные `PLAYWRIGHT_MODULE`, `BASE_URL` и `QA_OUTPUT` позволяют задать путь к Playwright, адрес локального сервера и файл отчёта.

Перед публикацией проверьте обе графические проекции каждого предмета, источники, скрытие и раскрытие ответов, возвращение из атласа к текущей карточке, сохранение отметок и максимальный размер текста на узком экране. Отдельно проверяются автономный HTML и опубликованная версия: успешная локальная сборка сама по себе не подтверждает обновление сайта.

## Публикация и обновления

GitHub Pages обслуживает папку `docs` ветки `main`. QR-код ведёт на постоянный адрес `https://evgk724.github.io/reliq-atlas/`.

Онлайн-приложение проверяет `version.json` при открытии, возвращении на вкладку и раз в минуту, пока вкладка видима. Перед переходом на новую версию проверяется готовность HTML. Автообновление откладывается во время тренировки, просмотра связанного пояснения из активной карточки и при несохранённом прогрессе. Настройки обновлений доступны в окне «О приложении».

Сохранённый `RELIQ.html` остаётся самостоятельной копией. Он открывается без сети; внешние источники и получение новой версии требуют подключения. Сайт можно добавить на экран «Домой» средствами браузера.
